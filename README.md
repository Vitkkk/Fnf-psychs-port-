# Psych Engine Android — Mobile Creator Fork

Mobile-first creator tooling for the Kviks Psych Engine Android 0.4.2 port.

This repository is a downstream overlay pinned to upstream commit `8d84350fa92ecdf2b359492e01524385df094851` from `kviks/Psych-Engine-Android`.

The first milestone is intentionally limited to the Week Editor, Chart Editor and Chart Event Editor. Gameplay code is not modified unless required for editor integration.
